# Contrato API vigente

El contrato implementado de la API textual y sus ejemplos están en
[API_TEXTO_WEB.md](API_TEXTO_WEB.md#contrato-canónico-apiv1).

Esta versión reemplaza el contrato preliminar: ofrece catálogo completo por
letra canónica, búsqueda de metadatos, detalle, capacidades, SGNS y TF-IDF,
y consulta por exactamente una semilla o texto libre. Audio/Mixto y evaluación
no están implementados. No se aceptan pesos ni controles sin implementación.
